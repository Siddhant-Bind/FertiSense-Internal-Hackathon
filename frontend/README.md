# FertiSense Web (React + Vite)

Frontend for PSAI01, the Sustainable Fertilizer Usage Optimizer.

## Run it

```bash
npm install
npm run dev          # http://localhost:5173
npm run build        # production build in dist/
```

With no backend configured, the app runs in **demo mode**: accounts and reports are stored in the browser
(`localStorage`) and the report is generated by `src/lib/engine.js`. To connect your backend, create `.env`:

```
VITE_API_URL=http://localhost:8000/api
```

## Pages and routes

| Route | Page | Access |
|---|---|---|
| `/` | Landing (Sign in / Sign up top-right) | Signed-out only |
| `/signin` | Sign in with email **or** phone + password | Signed-out only |
| `/signup` | Email, phone, password (+confirm), state + district | Signed-out only |
| `/dashboard` | Profile avatar, New recommendation, history list | Signed-in |
| `/recommendations/new` | State + district preloaded from profile, searchable village, soil type, crop type, growth stage, previously used fertilizers + quantity, optional own Soil Health Card values | Signed-in |
| `/reports/:id` | Report (opened after generation or from history) | Signed-in |
| `/profile` | Edit phone and district, sign out | Signed-in |

Routing uses `HashRouter` so it works on any static host. Switch to `BrowserRouter` if your host has SPA fallback.

## Folder structure

```
src/
  App.jsx                 routes
  main.jsx                entry
  context/AuthContext.jsx user session (signIn, signUp, signOut, updateUser)
  services/api.js         API layer: real backend if VITE_API_URL is set, otherwise mock
  lib/engine.js           recommendation logic used by the mock (mirror of backend output)
  lib/validation.js       email / Indian mobile / password rules
  data/districts.js       locations API: states, districts, lazy village loading (from the soil health CSV)
  data/locations/         index.json (state -> districts) + states/<state>.json (villages with N, P, K, pH, samples)
  data/agronomy.js        crops (dose + stages), soil defaults, fertilizer products
  components/             Header, AvatarMenu, DistrictPicker, Field, BagIcon, ScoreRing, RouteGuards...
  pages/                  Landing, SignIn, SignUp, Dashboard, NewRecommendation, Report, Profile, NotFound
  styles/global.css       design tokens (light + dark) and all styles
```

## Location data

States, districts and villages come from `final_soil_health_data.csv` (28 states, 550 districts, 87,899 villages).
The CSV is converted into `src/data/locations/` by:

```bash
python scripts/build-locations.py path/to/final_soil_health_data.csv
```

Only the small state -> district index ships with the app. Each state's village file (with village-level
N, P, K, pH and number of samples) is loaded when that state is chosen. The selected village's averages are used
as the soil values unless the farmer enters their own Soil Health Card values. Lat/long are not shipped.

## Backend contract (what `services/api.js` expects)

All authenticated calls send `Authorization: Bearer <token>`. Errors return a non-2xx status with
`{ "message": "...", "field": "email" }` (`field` optional; the form highlights that input).

| Method | Path | Body | Returns |
|---|---|---|---|
| POST | `/auth/signup` | `{ email, phone, password, state, district }` | `{ token, user }` |
| POST | `/auth/signin` | `{ identifier, password }` (identifier = email or phone) | `{ token, user }` |
| GET | `/me` | – | `user` |
| PATCH | `/me` | `{ phone?, state?, district? }` | `user` |
| GET | `/recommendations` | – | `[ { id, createdAt, district, crop, soilType, base, totalCost, soilScore } ]` |
| POST | `/recommendations` | see input below | `{ id }` |
| GET | `/recommendations/:id` | – | `{ id, createdAt, input, report }` |
| DELETE | `/recommendations/:id` | – | `{ ok: true }` |

`user` = `{ id, email, phone, state, district, createdAt }`

Master lists (strings are sent exactly as shown, matching the dataset labels):

- **Crop Type:** Sugarcane, Cotton, Millets, Pulses, Paddy, Wheat, Barley, Oil seeds, Tobacco, Ground Nuts, Maize
- **Soil Type:** Loamy, Sandy, Clayey, Black, Red
- **Fertilizer Name:** Urea, DAP, 28-28, 14-35-14, 20-20, 17-17-17, 10-26-26
- **Growth stage:** Seed, Seedling, Vegetative, Flowering, Fruiting

Recommendation **input** (all quantities are per acre):
```json
{ "state": "Maharashtra", "district": "Nashik", "village": "Adgaon",
  "villageSoil": { "n": 186.3, "p": 12.1, "k": 310.4, "ph": 7.9, "samples": 14 },
  "soilType": "Black", "crop": "Cotton", "growthStage": "Vegetative",
  "previousFertilizers": [
    { "fertilizer": "Urea", "quantity": 2, "unit": "bags", "kg": 90 },
    { "fertilizer": "DAP", "quantity": 50, "unit": "kg", "kg": 50 }
  ],
  "soilTest": { "N": "230", "P": "9", "K": "420", "pH": "8.1", "OC": "" } }
```
`previousFertilizers` is `[]` when nothing was entered; `soilTest` is `null` without a Soil Health Card.

Recommendation **report** (per acre; see `generateReport` in `lib/engine.js`):
```json
{
  "cropName": "Cotton", "base": "17-17-17", "baseName": "17-17-17",
  "ranking": [{ "name": "17-17-17", "p": 62 }],
  "soil": { "N": 230, "P": 9, "K": 420, "pH": 8.1, "OC": 0.5 },
  "ratings": { "N": "low", "P": "low", "K": "high" },
  "soilSource": "test", "soilScore": 67,
  "need": { "N": 61, "P": 24, "K": 18 },
  "plan": { "N": 61, "P": 24, "K": 20 },
  "buy": [{ "key": "17-17-17", "name": "17-17-17", "kg": 118, "bagSize": 50, "bags": 3, "cost": 3540 }],
  "totalCost": 4400,
  "growthStage": "Vegetative", "fullSeasonCost": 4400,
  "schedule": [
    { "growthStage": "Seed", "stage": "At sowing (basal)", "status": "moved", "items": { "17-17-17": 118, "Urea": 20 } },
    { "growthStage": "Vegetative", "stage": "At square (bud) formation, about 30 days", "status": "now", "includesCatchUp": true, "items": { "17-17-17": 118, "Urea": 60 } },
    { "growthStage": "Flowering", "stage": "At flowering, about 60 days", "status": "upcoming", "items": { "Urea": 43 } }
  ],
  "comparison": {
    "items": [{ "name": "Urea", "kg": 90 }], "nutrients": { "N": 50, "P": 23, "K": 0 },
    "cost": 1883, "saving": -2517, "notes": [{ "tone": "warn", "text": "..." }]
  },
  "advice": [{ "tone": "warn", "text": "..." }]
}
```
`comparison` is `null` when no previous fertilizer was entered. `buy` and `totalCost` cover only doses with status
`now` or `upcoming`; `status` is `moved` (missed, carried into today's dose while the crop is at Seed to Vegetative)
or `skipped` (missed at Flowering/Fruiting, too late to help). `soilSource` is `test`, `village` or `estimated`.

Fertilizer keys in `buy` and `schedule.items` are the Fertilizer Name strings above.
